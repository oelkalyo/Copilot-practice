# New Project

A simple HTML/CSS/JavaScript project template.

## Project Structure

```
new project/
├── index.html      # Main HTML file
├── styles.css      # Stylesheet
├── script.js       # JavaScript file
└── README.md       # This file
```

## Getting Started

1. Open `index.html` in your web browser
2. Customize the HTML content, CSS styles, and JavaScript functionality
3. Add more files as needed for your project

## Features

- Clean HTML structure
- Responsive CSS styling
- Basic JavaScript setup
- Ready to extend
